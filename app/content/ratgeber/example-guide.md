## Why the text layer matters

An application portal reads the text inside your PDF, not the picture of the page. A PDF exported from a word processor or from this app carries that text. A scan or a photo of a printout usually does not, unless someone ran text recognition on it.

## The one-minute check

1. Open the PDF in any viewer.
2. Select a line of text with the mouse and copy it.
3. Paste it into a plain text editor.

If the same words come out in the same order, the text layer is fine. If nothing is selectable, or the pasted text is scrambled, export the CV again from the source document instead of scanning it.

:::tip
Run the same check on the Word version if a portal asks for one. Text in text boxes and tables is where reading most often goes wrong.
:::

## What to keep in mind

- One file, named clearly, for example `CV_Firstname_Lastname.pdf`.
- Keep the file small; portals set their own upload limits.
- Contact details as plain text, not inside an image.
