This file only exists for the check scripts (seocheck.mjs, magazincheck.mjs). It is never built into the live site: the build reads app/content/magazin, and the checks copy this folder in next to it.

Send a PDF unless the job ad asks for something else. Keep a Word version ready for portals that require one.

## Check the text layer

Open the PDF, select all text and paste it into a plain text editor. If the text comes out in the right order, a parser can read it too.

## Frequently asked questions

### Do portals accept PDF?

Most do. What matters is a real text layer, not a scanned image.
